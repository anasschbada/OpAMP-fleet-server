Point your OpenTelemetry Collectors' opamp extension at the OpAMP endpoint
above with a bearer token from your AGENT token pool (never the API pool)
-- see deploy/k8s/collector-examples/ in the source repository for
example collector manifests and why they need no Kubernetes RBAC either.

Nothing this chart installed has a Role, RoleBinding, ClusterRole, or
ClusterRoleBinding attached to it -- see docs/RBAC.md in the source
repository for the full model and how to opt a namespace into the
(currently unused) future read-only cross-check pattern, if you ever need it.
